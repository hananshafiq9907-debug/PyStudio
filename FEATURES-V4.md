# PyStudio V4 Feature Matrix

## Working foundations
- FastAPI backend
- Health endpoint
- Project storage API
- Development Python execution endpoint
- WebSocket terminal transport
- WebSocket debugger transport
- Dockerized API
- Frontend backend bridge

## Frontend from V3
- Editor, tabs and explorer
- Autocomplete surface
- Problems
- Notebook
- Visualization
- AI workspace
- Settings/themes
- Responsive mobile layout
- Local persistence

## Production integrations still required
- Container/VM sandbox worker
- debugpy execution service
- real terminal shell inside sandbox
- pip/venv package manager inside sandbox
- authentication/session management
- database-backed projects
- Git/GitHub OAuth and server-side git
- collaboration via authenticated WebSockets
- LSP/Pyright-style language intelligence
- test/coverage/profiling workers
- cloud file/object storage
- secure server-side AI provider integration
- PWA service worker and offline cache
- observability, rate limiting and backups
